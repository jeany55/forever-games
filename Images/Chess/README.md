# Chess pieces

These textures are the "classic" piece set from
[ChessCraft Creative Commons](https://gitlab.com/zulban/chesscraft-creative-commons/-/tree/master/assets/Resources/Pieces/01_classic)
by Zulban (commit `62d207ad`), which that project in turn took from the Wikimedia Commons
[SVG chess pieces](https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces).

They are licensed under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/),
not under the MIT license that covers the rest of this addon. If you pass them on, changed or
not, it has to be under that same license and with this credit.

Changes made here: cropped to a common margin, scaled to 64, 128 and 256 pixels and converted
from PNG to TGA, by `Tools/convert_pieces.py`.
